# GeoLens Frontend

Интеллектуальная система поддержки принятия решений для геологоразведки.

## Технологии
- React 18
- React Router
- Leaflet (карты)
- Recharts (графики)
- Zustand (state management)
- Vite (сборщик)

## Установка
npm install

## Запуск
npm run dev

Откроется на http://localhost:3000

## Структура
frontend/
├── src/
│   ├── components/   # Компоненты
│   ├── pages/        # Страницы
│   ├── layouts/      # Layouts
│   ├── stores/       # Zustand stores
│   ├── services/     # API
│   ├── mock/         # Mock данные
│   └── styles/       # CSS
├── index.html
├── package.json
└── vite.config.js
