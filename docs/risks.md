# Журнал рисков

Обновляется на планировании в понедельник. Закрытые риски не удаляются — меняется статус.

## Р1. Геологи не отвечают
Вероятность: высокая · Влияние: среднее · Статус: активен
Меры: работаем по допущениям (assumptions.md); отправили короткую версию вопросов; уточняем у преподавателя, может ли он отвечать на вопросы по скоупу.

## Р2. Мало известных объектов на площади
Вероятность: средняя · Влияние: высокое · Статус: активен
Меры: до окончательного выбора площади проверить, что есть 10+ объектов с координатами; резервная площадь — кратон Гоулер (Австралия), медь; базовый алгоритм работает без обучающей выборки.

## Р3. Мало открытых данных по площади
Вероятность: средняя · Влияние: высокое · Статус: активен
Меры: для Енисейского кряжа опираемся на глобальные слои (EMAG2, WGM2012, SRTM, Sentinel-2); резерв — Гоулер, где открыт полный пакет данных SARIG.

## Р4. Таблица признаков не собрана к неделе 8
Вероятность: средняя · Влияние: критическое · Статус: активен
Меры: начинаем с 2–3 слоёв, а не со всех сразу; при отставании сужаемся до 1–2 источников, как разрешает бриф.

## Р5. Завышенные метрики из-за утечки
Вероятность: высокая · Влияние: высокое · Статус: активен
Меры: блочная пространственная кросс-валидация; не используем признаки инфраструктуры (расстояние до дорог, посёлков); проверяем любую метрику выше 0,9.
