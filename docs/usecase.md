## Описания

### ВИ-1. Просмотреть карту площади
Актёр: Пользователь
Цель: увидеть исследуемую территорию.
Предусловие: приложение запущено.
Основной поток:
1. Пользователь открывает приложение в браузере.
2. Система показывает карту с подложкой, центрированную на площади, и контур её границ.
3. Пользователь масштабирует и перемещает карту.
Постусловие: пользователь видит площадь на карте.

### ВИ-2. Включить / выключить слой данных
Актёр: Пользователь
Цель: посмотреть исходные данные по площади.
Предусловие: открыта карта площади (ВИ-1).
Основной поток:
1. Пользователь открывает список слоёв.
2. Пользователь отмечает слой (например, магнитное поле).
3. Система отображает слой с легендой не дольше чем за 2 секунды.
Альтернативный поток:
2а. Пользователь снимает отметку → слой скрывается.
Постусловие: на карте отображены выбранные слои.

### ВИ-3. Просмотреть карту перспективности
Актёр: Пользователь
Цель: найти зоны с высокой оценкой.
Предусловие: карта рассчитана (ВИ-9), открыта карта площади (ВИ-1).
Основной поток:
1. Пользователь включает слой «Карта перспективности».
2. Система отображает растр оценок с цветовой шкалой и легендой.
Расширение: ВИ-7 — пользователь может переключить метод расчёта.
Постусловие: пользователь видит, где оценка выше.

### ВИ-4. Получить оценку ячейки
Актёр: Пользователь
Цель: понять, насколько перспективна ячейка и почему.
Предусловие: отображается карта перспективности (ВИ-3).
Основной поток:
1. Пользователь кликает по ячейке.
2. Система показывает координаты ячейки и оценку от 0 до 1.
3. Система показывает вклад признаков (ВИ-5).
Альтернативный поток:
1а. Клик за пределами площади → система сообщает «Нет данных для этой точки».
Постусловие: пользователь видит оценку и её объяснение и может решить, согласен ли он с ней.

### ВИ-5. Просмотреть вклад признаков
Актёр: Пользователь (вызывается из ВИ-4)
Цель: понять, из чего сложилась оценка.
Основной поток:
1. Система показывает список признаков ячейки, отсортированный по величине вклада.
2. Положительный и отрицательный вклад выделены разным цветом.
Постусловие: пользователь видит, какие признаки повысили и понизили оценку.

### ВИ-6. Просмотреть известные месторождения
Актёр: Пользователь
Цель: проверить, попадают ли известные объекты в зоны высокой оценки.
Предусловие: открыта карта площади (ВИ-1).
Основной поток:
1. Пользователь включает слой «Известные месторождения».
2. Система отображает объекты точками.
3. При наведении на точку система показывает название объекта.
Постусловие: пользователь сопоставляет месторождения с картой перспективности.

### ВИ-7. Сравнить базовый алгоритм и модель (желательно)
Актёр: Пользователь
Цель: увидеть, где оценки двух методов расходятся.
Предусловие: отображается карта перспективности (ВИ-3).
Основной поток:
1. Пользователь переключает метод: «Базовый алгоритм» / «Модель».
2. Система перерисовывает карту выбранным методом.
3. Оценка и вклад признаков по клику показываются для выбранного метода.
Постусловие: пользователь видит, как оценка зависит от метода.
