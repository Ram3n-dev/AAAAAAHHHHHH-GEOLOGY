# Устав проекта

25.09.2026 

## 1. Название

GeoLens — рабочее название проекта.

Тема: «Разработка интеллектуальной системы поддержки принятия решений при поиске и разведке месторождений полезных ископаемых».

## 2. Обоснование

Решение о том, на какие участки тратить бюджет разведки, — самое дорогое в геологоразведке: каждый следующий этап стоит в десятки раз больше предыдущего.
Главный геолог принимает его вручную, сводя в голове разнородные данные: геохимию, геофизику, космоснимки, рельеф, старые отчёты. Данные в разных форматах, масштабах и системах координат.
В результате выбор участков субъективен, его сложно воспроизвести и защитить перед руководством.

## 3. Цель

Создать веб-систему, которая сводит разнородные геоданные по территории, строит карту перспективности, ранжирует участки и объясняет каждую оценку.

Цель семестра 1: к защите PoC (неделя 16) показать работающую демонстрацию на одной площади, где ранжирование заметно лучше случайного — в топ-10% площади попадает существенная доля известных месторождений.

## 5. Пользователь

Главный геолог поисковой партии или аналитик геологоразведочной компании. Распределяет ограниченный бюджет между участками и должен уметь обосновать решение.
Решение принимает человек. Система даёт ему обоснованную опору.

## 6. Результаты

Семестр 1 — прототип (PoC):
- воспроизводимая таблица признаков по одной площади
- базовый алгоритм (веса признаков) и модель машинного обучения
- карта перспективности с объяснением оценки по клику на ячейку
- отчёт о качестве с разбором смещения изученности
- пояснительная записка и журнал решений

Семестр 2 — минимальный продукт (MVP): загрузка своих данных, сценарный анализ, работа с участками, экспорт результатов.

## 7. Границы

Входит в семестр 1:
- одна площадь: золоторудный пояс Енисейского кряжа, 58.5–60.6° с. ш., 92.3–95.0° в. д. (см. Р-004)
- один вид полезного ископаемого: золото
- данные скачаны заранее и лежат в хранилище проекта
- один пользователь, без регистрации и авторизации
- модель обучается в ноутбуке, в сервис отдаётся готовый растр оценок
- интерфейс — одна страница

Не входит в проект:
- 3D-моделирование рудных тел
- подсчёт запасов по требованиям ГКЗ
- обработка сейсмики и интерпретация каротажа
- замена Micromine, Leapfrog, ArcGIS
- мобильное приложение

## 9. Критерии успеха (приёмка PoC)

- Проект разворачивается одной командой из репозитория
- Таблица признаков воспроизводится скриптом из сырых данных
- Есть карта перспективности по площади
- Качество измерено блочной пространственной кросс-валидацией и сравнено с базовым алгоритмом и случайным ранжированием
- В отчёте разобрано смещение изученности
- По клику на ячейку видна оценка и вклад признаков
- Есть журнал решений и пояснительная записка
